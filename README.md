# whisper-audio-to-text

Скрипт на Python: превращает аудио или видео в текст локально, на своём компьютере.
Работает через модель Whisper от OpenAI, интернет нужен только один раз — чтобы скачать модель.

По умолчанию настроен на русский язык и модель `small`.

## Что умеет

- Распознаёт речь из видео и аудио: `mp4`, `mkv`, `mov`, `mp3`, `wav`, `m4a` и всё, что читает ffmpeg.
- Пишет результат рядом с исходным файлом: `видео.mp4` -> `видео.txt`.
- Работает без интернета после первой загрузки модели.
- Ничего не отправляет на сторонние сервисы: весь текст остаётся у вас.
- Делает субтитры с таймкодами через `transcribe_srt.py`: SRT, VTT, JSON и вжигание в видео.

## Требования

- **Python 3.8 или новее** — https://www.python.org/downloads/
- **ffmpeg** — без него Whisper не прочитает файл.
- **Библиотека Whisper** — ставится одной командой, вместе с ней приедет PyTorch.

## Установка на Windows

1. Установите Python, при установке отметьте галочку **Add Python to PATH**.
2. Скачайте ffmpeg: https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
   Распакуйте архив, найдите внутри `ffmpeg.exe`, скопируйте его в папку `C:\`.
   Либо добавьте папку с `ffmpeg.exe` в переменную `PATH`.
3. Откройте командную строку и установите библиотеку:

```bash
pip install openai-whisper
```

4. Проверьте, что ffmpeg виден системе:

```bash
ffmpeg -version
```

Если команда не найдена — значит `ffmpeg.exe` лежит не там, где ищет система.

## Как пользоваться

```bash
python transcribe.py C:\video\интервью.mp4
```

Что произойдёт:

1. Первый запуск скачает модель `small` (около 470 МБ), дальше она берётся из кэша.
2. Скрипт покажет распознанный текст в консоли.
3. Рядом с файлом появится `интервью.txt` с тем же текстом.

## Субтитры с таймкодами

Для субтитров используется отдельный скрипт `transcribe_srt.py`. Установите зависимости:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python transcribe_srt.py video.mp4 --lang ru --model small
```

Рядом с видео появятся:

- `video.srt` — субтитры для плееров и монтажа;
- `video.vtt` — для веба;
- `video.json` — реплики с началом и концом.

Вжечь субтитры в видео:

```bash
python transcribe_srt.py video.mp4 --lang ru --model small --burn
```

Результат: `video_subtitled.mp4`. Стиль по умолчанию: белый текст, чёрная обводка, снизу.

Полезные параметры: `--max-line`, `--max-duration`, `--max-gap`, `--min-duration`, `--formats srt,vtt,json`, `--out-dir`, `--backend faster|openai|auto`, `--device cpu|cuda`, `--compute-type int8|float16`, `--ffmpeg`, `--keep-audio`, `--self-test`.
## Модели Whisper и как их менять

Модель задана в коде, в файле `transcribe.py`, строка:

```python
model = whisper.load_model("small")
```

| Модель | Размер | Скорость на процессоре | Качество |
|---|---|---|---|
| `tiny` | ~75 МБ | самая быстрая | черновое, ошибок много |
| `base` | ~140 МБ | быстрая | терпимо для чистой речи |
| `small` | ~470 МБ | средняя | хорошее, стоит по умолчанию |
| `medium` | ~1,5 ГБ | медленная | очень хорошее |
| `large` | ~3 ГБ | очень медленная | лучшее |

Практика: для интервью и лекций берите `medium`, для коротких роликов хватает `small`.
На слабом ноутбуке `large` будет считаться часами.

Язык тоже задан в коде, там же, где вызов распознавания:

```python
result = model.transcribe(file, language="ru", fp16=False)
```

`language="ru"` — русский. Для другого языка поставьте его код: `en`, `uk`, `de`, `fr` и так далее.
Если язык неизвестен, уберите параметр совсем и задайте `language=None` — Whisper определит язык сам, но точность будет ниже.

`fp16=False` — режим для работы на процессоре. На видеокарте NVIDIA его можно поставить в `True`, тогда счёт будет быстрее.

## Типичные ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| `ffmpeg not found` | ffmpeg не установлен или не в PATH | скопировать `ffmpeg.exe` в `C:\` или добавить в `PATH` |
| `No module named whisper` | библиотека не установлена | `pip install openai-whisper` |
| очень долго считает | выбрана большая модель или нет видеокарты | поставить модель `small` или `base` |
| `CUDA out of memory` | не хватает памяти видеокарты | поставить `fp16=False` и модель меньше |
| `Файл не найден` | неверный путь | путь с пробелами берите в кавычки |
| качает модель при каждом запуске | нет прав на запись кэша | запустить от пользователя с правами записи в профиль |

## Ограничения

- Один файл за запуск, пакетной обработки папки нет.
- `transcribe.py` выводит сплошной текст без тайм-кодов. Для субтитров используйте `transcribe_srt.py`.
- Нет автоматической расстановки знаков препинания по абзацам — Whisper ставит их сам, но грубо.
- Качество падает на шумной записи, музыке и при нескольких говорящих одновременно.
